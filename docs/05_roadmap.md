# 05. Roadmap

## Fase 1: Preparación del proyecto

- Definir idea final.
- Crear repositorio GitHub.
- Crear documentación inicial.
- Definir arquitectura.
- Definir stack técnico.
- Preparar estructura base.

## Fase 2: Backend inicial

- Crear proyecto FastAPI.
- Configurar entorno Python.
- Crear endpoints base.
- Configurar PostgreSQL.
- Crear modelos iniciales.
- Añadir autenticación básica.

## Fase 3: Frontend inicial

- Crear proyecto React con Vite.
- Configurar Tailwind CSS.
- Crear layout principal.
- Crear navegación.
- Crear formulario de análisis.
- Crear dashboard inicial.

## Fase 4: Motor de análisis

- Crear motor de scoring.
- Definir reglas de riesgo.
- Calcular puntuación global.
- Calcular puntuaciones por área.
- Generar mapa de riesgos.

## Fase 5: Integración IA

- Diseñar prompts.
- Generar políticas de seguridad.
- Generar recomendaciones.
- Generar resumen ejecutivo.
- Guardar resultados en base de datos.

## Fase 6: Informes PDF

- Crear plantilla de informe.
- Generar PDF desde backend.
- Añadir descarga desde frontend.

## Fase 7: Despliegue

- Crear Dockerfile para backend.
- Crear Dockerfile para frontend.
- Crear docker-compose.
- Configurar Nginx.
- Desplegar en Hetzner.
- Configurar HTTPS.

## Fase 8: Documentación final

- Capturas de pantalla.
- Evidencias de desarrollo.
- Guía de despliegue.
- Manual de usuario.
- Informe final PDF.
- Preparación de presentación oral.
