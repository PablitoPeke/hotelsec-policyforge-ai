# 03. Funcionalidades

## MVP de la Práctica 1

### 1. Formulario de análisis

Formulario guiado para recopilar información sobre:

- Perfil del hotel.
- Sistemas tecnológicos.
- Seguridad actual.
- Datos personales tratados.
- Riesgo operativo.
- Personal y formación.
- IoT e instalaciones.

### 2. Evaluador de madurez

El sistema calculará una puntuación global entre 0 y 100.

También mostrará puntuaciones parciales por área para que el usuario sepa dónde está mejor y peor.

### 3. Mapa de riesgos

Cada análisis generará una lista de riesgos con:

- Nombre del riesgo.
- Descripción.
- Probabilidad.
- Impacto.
- Severidad.
- Recomendación.

### 4. Generador de políticas

La IA generará políticas adaptadas al perfil de la empresa.

Políticas iniciales:

- Contraseñas.
- Copias de seguridad.
- Uso de dispositivos.
- WiFi para huéspedes.
- Uso del PMS y sistemas de reservas.
- Proveedores externos.
- Respuesta a incidentes.
- Protección de datos personales.

### 5. Dashboard

El dashboard mostrará:

- Puntuación global.
- Riesgo general.
- Riesgos críticos.
- Políticas generadas.
- Tareas pendientes.
- Últimos análisis.

### 6. Informe PDF

El usuario podrá descargar un informe con:

- Resumen ejecutivo.
- Perfil de empresa.
- Puntuación de madurez.
- Mapa de riesgos.
- Recomendaciones.
- Políticas generadas.
- Plan de acción.
